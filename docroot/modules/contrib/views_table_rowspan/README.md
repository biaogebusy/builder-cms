## About
Views Table Rowspan provides a Views style plugin called Table Rowspan.
It groups table rows by field values and merges cells with identical values using the HTML rowspan attribute.

# Features
+ Groups rows by field values or rendered field output.
+ Supports multiple grouping levels.
+ Merges repeated table cells using the HTML rowspan attribute.
+ Extends the standard Views table style.

## Usage
1. Create or edit a View that displays fields.
2. Select Table Rowspan as the View format.
3. Add the fields you want to display.
4. Configure grouping for the field whose repeated values should be merged.
5. Enable the Merge rows in group option.
